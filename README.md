# 🧾 Sistema de Inventario y Facturación – Minimarket “La Esquina”

Este proyecto consiste en el desarrollo de un **Sistema de Inventario y Facturación** diseñado para optimizar la gestión de productos, ventas y servicios adicionales en un minimarket.  
El sistema se basa en la aplicación de **patrones de diseño de software**, lo que garantiza un código **modular, escalable y mantenible**.

---

## 🎯 Objetivo General

Diseñar un sistema que **automatice los procesos comerciales** del minimarket “La Esquina”, aplicando **patrones de diseño** que mejoren su eficiencia, mantenibilidad y adaptabilidad.

---

## ⚙️ Patrones de Diseño Aplicados

- **Factory Method:** Gestión flexible de distintos tipos de documentos de venta (boleta, factura, nota de crédito).  
- **Singleton:** Control de una única instancia para la conexión a la base de datos.  
- **Strategy:** Implementación dinámica de distintas políticas de descuento.  
- **Observer:** Sincronización en tiempo real entre ventas e inventario.  
- **Composite:** Tratamiento homogéneo de productos individuales y combos.  
- **Decorator:** Adición de servicios extra como delivery o empaquetado sin alterar la estructura base.

---

## 💡 Beneficios del Sistema

- Automatización de procesos de facturación e inventario.  
- Reducción de errores administrativos.  
- Mayor flexibilidad y escalabilidad del sistema.  
- Código más limpio, reutilizable y fácil de mantener.
